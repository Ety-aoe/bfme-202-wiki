# BFME 2 RotWK Wiki — Patch 2.02 v9.7.7

Interactive bilingual community wiki for **The Battle for Middle-earth II: The Rise of the Witch-king**, Patch **2.02 v9.7.7**.

The public site is designed to expose gameplay data reconstructed from the game's INI files: units, heroes, buildings, powers, summons, debuffs, damage types, armor profiles, technical weapons/scalars, unit comparison and damage calculation.

## Production site

GitHub Pages serves the repository root. The public build is the root `index.html`.

## Updating safely

1. Keep the current `main` branch as the public/stable version.
2. Prepare and test changes before replacing `index.html`.
3. Commit the tested build to `main` only when validated.
4. Git history provides an immediate rollback path if a release introduces a regression.

Gameplay target: **Patch 2.02 v9.7.7**.
